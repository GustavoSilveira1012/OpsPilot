# OPS-006 — Incident Management UI

## Integration

This PR is based on the current OPS-005 implementation branch, not main. Merge OPS-005 first, then retarget or rebase OPS-006 onto main. No UI-side authorization replaces the NestJS tenant and role checks.

## Routes

- `/[org]/incidents`: protected incident catalog, server-side status/severity/service filters, 25-item pagination, page-local search, accessible create form for OWNER/ADMIN.
- `/[org]/incidents/[id]`: protected incident overview, status/severity/summary updates for OWNER/ADMIN, append-only timeline and note creation for active members.
- Workspace navigation gains Incidents.

The interface uses Supabase's existing session and the NestJS API over bearer-authenticated HTTP. All server reads are no-store and tenant-scoped. It retains existing white/green OpsPilot CSS modules.

## Backend dependency

OPS-005 creates/reads/updates incidents and adds notes. Optional responder management, linked-service changes, and strict timeline sequencing are OPS-005E additions and must be merged before those corresponding UI controls are implemented. OPS-006 must not claim those features are already live.
