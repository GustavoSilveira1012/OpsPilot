# Sprint 1 · OPS-001 · Monorepo foundation

## Goal

Create a reproducible, typed, linted full-stack workspace that can build and deploy a web app and API independently while sharing contracts and configuration.

## Acceptance criteria

- [x] pnpm workspace and Turborepo task graph use the agreed `apps/web`, `apps/api`, `packages/*`, `infra`, and `docs` layout.
- [x] `apps/web` uses Next.js App Router and React, with an OpsPilot starter screen.
- [x] `apps/api` uses NestJS, a versioned `/api/v1/health` route, exact-origin CORS configuration, and Helmet security headers.
- [x] shared TypeScript and ESLint flat configs are consumed by workspace packages.
- [x] API and web environment examples exist and real environment files are ignored.
- [x] GitHub Actions runs frozen install, formatting, lint, typecheck, and production build checks.
- [x] The generated `pnpm-lock.yaml` pins the workspace dependency graph.
- [x] Formatting, lint, typecheck, and production build gates pass locally.

## Out of scope

Incident persistence, authentication, database provisioning, integrations, and production deployment are subsequent sprint work.
